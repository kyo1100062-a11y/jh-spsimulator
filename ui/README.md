# 사업비 산출 및 보조금/자부담 계산 시뮬레이터

## 프로젝트 개요

내부 직원이 사업의 총사업비를 입력하고 비율을 조정하여, 재원별(국비, 도비, 시비) 보조금액 및 자부담액을 정확하고 신속하게 산출할 수 있도록 지원하는 웹 애플리케이션입니다.

## 기술 스택

- **HTML5**: 구조 및 레이아웃
- **CSS3**: 다크 테마 스타일링
- **JavaScript (ES6+)**: 계산 로직 및 이벤트 처리
- 프레임워크 없음 (순수 바닐라 JavaScript)

## 파일 구조

```
ui/
├── index.html      # 메인 HTML 파일
├── style.css       # 스타일시트 (다크 테마)
├── script.js       # 계산 로직 및 이벤트 처리
└── README.md       # 프로젝트 설명서
```

## 실행 방법

1. 프로젝트를 로컬에 클론 또는 다운로드합니다.
2. `index.html` 파일을 웹 브라우저에서 열기만 하면 됩니다.
   - 더블클릭으로 실행
   - 또는 웹 브라우저에서 파일 열기
3. 별도의 빌드 도구나 서버가 필요하지 않습니다.

## 주요 기능

### 1. 메타데이터 입력
- 보조사업자, 소재지, 사업내역, 업체명, 비고 입력

### 2. 실시간 계산
- 총사업비 자동 계산
- 교부결정액 입력/자동계산
- 사업비 산출금액 자동 계산
- 보조금 테이블 계산 (국비, 도비, 시비)
- 자부담 테이블 계산

### 3. 검증 기능
- 검증하기 버튼으로 입력값 검증
- 보조금+자부담 합계 검증
- 비율 100% 초과 검증
- 음수 값 검증

## 개발 환경 설정

### 요구사항
- 최신 웹 브라우저 (Chrome, Edge, Firefox, Safari 등)
- 별도의 설치나 설정 불필요

### 로컬 개발 서버 실행 (선택사항)

Python이 설치되어 있다면:

```bash
# Python 3
python -m http.server 8000

# Python 2
python -m SimpleHTTPServer 8000
```

그 다음 브라우저에서 `http://localhost:8000` 접속

또는 Node.js가 설치되어 있다면:

```bash
npx http-server
```

## 계산 로직

계산 로직은 `script.js` 파일의 함수로 구현되어 있습니다:
- `calculateTotalCost()`: 총사업비 계산
- `calculateProjectCost()`: 사업비 산출금액 계산
- `calculateSubsidyTable()`: 보조금 테이블 계산
- `calculateSelfContributionTable()`: 자부담 테이블 계산

엑셀 수식과 동일하게 동작하도록 구현되었으며, 필요시 해당 함수만 수정하면 됩니다.
